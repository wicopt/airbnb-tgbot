# airbnb-tgbot

Telegram-бот на микросервисной архитектуре для учёта финансов по квартирам в кондоминиуме. Участники группы вносят доходы и расходы, смотрят статистику и ROI, получают уведомления о новых платежах прямо в Telegram.

## Возможности

- Добавление платежей (доход / расход) через диалог с выбором категории; категории можно создавать прямо в процессе
- Общие(разделяются пропорционально доходам между квартирами) и простые категории
- Статистика и ROI за период, конвертация валют (в т.ч. RUB) через exchangerate-api.com
- Управление группой: инвайт-коды, участники, исключение из группы
- Автоматический разбор платежей из почты Gmail
- Уведомления участникам группы о новых платежах: отдельными сообщениями (до 10 платежей) или одной сводкой (больше 10)
- Резервное копирование PostgreSQL в Google Drive

## Архитектура

| Сервис | Стек | Назначение |
|---|---|---|
| `tg-service` (`telegram-bot`) | Python, aiogram | Telegram-бот: хендлеры, FSM, клавиатуры |
| `auth-service` | Java, Spring Boot | Группы, участники, инвайт-коды, определение группы пользователя |
| `payment-service` | Java, Spring Boot | Платежи и категории, баланс |
| `statistics-service` | Java, Spring Boot | Статистика и ROI |
| `gmail-service` | Node.js | Парсинг писем Gmail и создание платежей |
| `pg-backup` | pg_dump + rclone | Бэкап БД в Google Drive |

Инфраструктура: PostgreSQL, RabbitMQ, Docker Compose.

**Взаимодействие сервисов**

- Асинхронно через RabbitMQ: запросы статистики/ROI, события о платежах, уведомления (request/response сопоставляются по correlation ID)
- Синхронно по HTTP: `tg-service` → `auth-service` (`GET /api/auth/user-group/{userId}`), запрос защищён статическим заголовком `X-Service-Key`
